# Участие в разработке

Репозиторий публичный. Прямое изменение исходников, настроек и публикация
релизов доступны владельцу `rkislov`. Другим пользователям доступны Issues
и Pull Requests из собственных forks. PR принимает и сливает владелец.
Публичность и Apache-2.0 позволяют также изменять и распространять свои копии.

Для сообщения об ошибке укажите версию SRK, ОС, архитектуру, шаги повторения,
ожидаемый и фактический результат. Удалите из журналов пароли, ключи,
токены, персональные данные и адреса внутренней инфраструктуры.

Для изменения создайте fork, отдельную ветку и PR в `main`. Опишите причину,
результат и выполненные проверки. Для Go-кода выполните `make test`, для
пакета ALT — `make altlinux`. Не добавляйте `.local`, `.work`, ключи,
рабочие конфигурации, базы, копии пользователей и сборочные артефакты.
Изменения распространяются на условиях Apache License 2.0.
