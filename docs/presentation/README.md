# Презентация GData SRK 0.9.2

[Скачать презентацию PowerPoint](GData-SRK-0.9.2.pptx).

10 слайдов: архитектура, обзор интерфейса, создание задания, результат копирования,
восстановление, права оператора, хранилища, ALT Linux 10 и материалы проекта.

Все скриншоты заново сняты 2 ноября 2026 года с текущего интерфейса GData SRK
0.9.2 на отдельном локальном демонстрационном стенде. Архивные снимки предыдущих
версий не используются. Файловая копия, проверка целостности и пробное
восстановление выполнены на тестовом источнике. Формы нового задания и
пользователя показывают примеры заполнения без сохранения.

Оригинальные PNG находятся в `screenshots/`. Данные и показатели стенда
не являются оценкой производительности или подтверждением промышленной
приёмки ALT Linux. Источники и пояснения находятся в заметках слайдов.
